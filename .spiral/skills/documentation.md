# Documentation Skill Instructions

When generating documentation:
1. Extract function signatures, class definitions, and module exports.
2. Produce structured Markdown documentation with code examples and usage snippets.
3. Include parameter types, return values, and exception specifications.
4. Keep explanations concise, professional, and well-formatted with markdown tables where applicable.

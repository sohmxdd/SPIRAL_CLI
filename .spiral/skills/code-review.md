# Code Review & Refactoring Skill Instructions

When performing a code review:
1. Inspect target code files for syntax correctness, code readability, performance bottlenecks, and security vulnerabilities.
2. Check for unused variables, missing exception handlers, memory leaks, and non-idiomatic patterns.
3. Suggest concrete, refactored replacement code blocks with rationale.
4. Highlight any potential breaking changes or edge cases.
